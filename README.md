# Mods

Fabric 1.20.1 mods built on [Palladium](https://modrinth.com/mod/threetag-palladium):

- [`heroes/`](heroes/README.md) - Hulk, Viltrumites, symbiotes, the Infinity Stones (after Pugmeowla's Infinity Stone Core), races, a space system and more.
- [`fisks-superheroes/`](fisks-superheroes/README.md) - a recreation of Fisk's Superheroes: Iron Man, Captain America, Thor, Spider-Man, Black Panther, Superman, Batman and the Flash.
- [`tools/validate_palladium_json.py`](tools/validate_palladium_json.py) - checks Palladium JSON (powers, suit sets, items, recipes, render layers) against Palladium's source without starting the game.
